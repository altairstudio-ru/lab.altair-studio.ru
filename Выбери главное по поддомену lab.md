На основе анализа диалогов и зафиксированных концепций, вот **главное по поддомену lab.altair-studio.ru**:

### **1\. Формат и позиционирование**

* **Не сухая документация и не скучный wiki**, а **открытый инженерный журнал / playbook студии** (lab вместо docs или knowledge).  
* **Задачи поддомена:**  
  1. Накопление интеллектуального капитала и систематизация личного опыта.  
  2. Генерация органического низкочастотного (long-tail) SEO-трафика.  
  3. Демонстрация глубокой инженерной экспертизы и прогрев клиентов («продажа без продажи»).  
  4. Верх воронки с конверсией на коммерческие услуги основного сайта altair-studio.ru.

### **2\. Контентная модель и связь с Obsidian**

* **Принцип Pipeline:** Заметки не публикуются автоматически. Личный Obsidian служит «черновой кухней», а lab — «сервированным столом», куда отбираются и дорабатываются готовые материалы (в ритме \~1 статья в 1–2 недели).  
* **5 ключевых контентных колонок:**  
  1. **Система:** UI Kit, дизайн-токены, сравнение архитектур, темы.  
  2. **Инженерия:** разборы скорости, PageSpeed 100/100, Core Web Vitals, 0.4 сек загрузки.  
  3. **Кейсы-разборы:** технические постмортемы и решения сложных производственных задач (а не просто скриншоты портфолио).  
  4. **Модули платформы:** разбор работы модулей (MOD 01, Telegram-лиды, калькуляторы).  
  5. **Playbook студии:** процессы оценки, чеклисты, стандарты качества, декомпозиция смет.

### **3\. Визуальный код и тема**

* **Тема: Modern Tech (Slate)**.  
  * Палитра: спокойный темно-серый Slate (\#1E293B / \#0F172A) \+ Digital Blue (\#3B82F6) \+ акцентный Cyan (\#38BDF8).  
  * **Почему не Sapphire:** сапфировая тема Core отдана основному сайту altair-studio.ru, а для lab нужен нейтральный рабочий фон, оптимизированный под комфортное чтение длинных лонгридов (1500–3000 слов), кода, таблиц и схем без усталости глаз.  
* **Общая ДНК бренда сохраняется:** шрифтовая пара Inter \+ JetBrains Mono, тонкие границы, радиусы 6/10/14px и blueprint-сетка на фоне.

### **4\. Технический стек реализации**

* **Astro** (с точечным подключением компонентов AltaiR UI Kit / shadcn):  
  * Нативная работа с Markdown/MDX (прямой мост для переноса статей из Obsidian).  
  * Zero JS по умолчанию и эталонный результат PageSpeed 100/100 на мобильных устройствах, что полностью подтверждает слоган инженерной студии.  
  * Быстрая статическая генерация, готовые RSS, sitemap и бесплатный деплой на Vercel.
